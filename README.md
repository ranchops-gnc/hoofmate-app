# HoofMate

AI-powered horse management platform built for ranchers,
horse owners, trainers, and rodeo competitors.

## Features

- Horse Profiles
- Health Records
- Vaccination Tracking
- Ride Logging
- Care Scheduling
- Emergency Contacts
- AI Ranch Assistant
- Pasture Management
- Weight Tracking

## Stack

- Astro
- Node.js
- PostgreSQL
- Docker
- Cloudflare
- Nginx Proxy Manager
